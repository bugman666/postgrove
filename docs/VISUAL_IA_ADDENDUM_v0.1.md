# 视觉 / IA 补充 v0.1（Issue #2）

在 VISUAL_SYSTEM_v0 基础上，为完整路线图**预留导航**，**不绑死 P0 实现**。

## 导航预留（桌面侧栏 / 手机抽屉）

| 项 | P0 | P1+ |
|----|----|-----|
| 收件箱 | 必现 | ✓ |
| 写信 | 必现 | ✓ |
| 已发送 | 可隐藏或灰置占位 | 启用 |
| 垃圾邮件 | 可隐藏或灰置占位 | 启用 |
| 垃圾箱 | 可隐藏或灰置占位 | 启用 |
| 地址 | 必现 | ✓ |
| 设置 | 必现 | 扩展 |
| 搜索 | 顶栏可留输入框占位（禁用或「即将推出」） | 启用 |
| 星标 / 未读 | 不进 P0 主导航 | 筛选芯片 |

P0 实现允许：**只渲染收件箱 · 写信 · 地址 · 设置**；文件夹与搜索用注释/feature flag 预留 slot，避免以后大改布局。

## 阅读页

- P0：删除 + **回复入口**（按钮可见；行为 = 预填写信或占位文案）  
- P1：回复 / 全部回复 / 转发 真实可用

颜色与字号仍用 VISUAL_SYSTEM_v0；无需为 P1 改主色。侧栏宽度建议预留 `~200px`，便于后加文件夹列表。
