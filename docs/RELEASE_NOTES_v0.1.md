# Postgrove v0.1 — 首发说明（草案）

**一句话**：自有域名上的边缘邮箱——Cloudflare Workers 上收信、读信、写信、管附件；小团队值守 + 自有域开发者 API。不是公共临时邮。

## 你可以用它做什么

- 在本域开多个地址，网页收件箱读信 / 删信 / 附件下载  
- 写信、回复 / 全部回复 / 转发；草稿、已发送、垃圾箱等系统文件夹  
- 搜索、未读、星标、基础会话串  
- 小团队成员 + 配额；值守台审计与轻概览  
- 入站 webhook / 转发（签名 + 失败可查；URL 走安全校验）  
- `/api/v1` 与开发者短暂收件箱（等信 / OTP）；本域 `+tag` 别名与 API Key 配额  

## 刻意不做

- 第三方临时邮箱聚合 / 公共即抛邮箱池  
- 日历、通讯录、完整 IMAP 客户端替代  
- 企业套件式重型 BI / 皮肤商店  

## 部署者须知

你负责：域名、Email Routing、出站提供商额度与反垃圾。公开注册默认关闭（需自行配置 Turnstile 才开）。

本地：Node 22+，`npm i && npm run check && npm test`，见 README。
